HOM Screenshot Filename Renamer

Drop a screenshot or select an image, then generate a GitHub-friendly filename for the HOM screenshots folder.

1. Add a screenshot

Drop image here or click to select a PNG, JPG, GIF, or WebP file

You can also paste a filename here without selecting a file.

2. Generate clean filename

Current rule
  • Extracts date and time from names like Screenshot 2026-05-28 at 11-44-36 ....
  • Converts accents and special characters to a clean lowercase slug.
  • Uses hyphens inside the title and underscores between main sections.
  • Keeps the original file extension.
Example output:
2026-05-28_11-44-36_robyn-orlin-et-camille-la-beaute-des-eaux-qui-chantent-philharmonie-de-paris.png
